# VANTARO

React landing page for VANTARO, with the [React Bits](https://reactbits.dev) `DarkVeil` animation behind the original header copy.

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

## Header

The hero keeps the original German headline, lede, and CTAs. `DarkVeil` fills the header/hero background (`hueShift={46}`, scanlines on) via `ogl`.

# Vantaro – Payment Security Policies

Policies for Vantaro's ProCredit Bank integration (one-time payments only, no stored cards or tokens),
for ProCredit's "Requirements for implementing recurring payments".

| Document | What it covers | ProCredit requirement |
|---|---|---|
| [access-control-policy.md](access-control-policy.md) | Who can access payment data and secrets, MFA, joining/leaving, quarterly access review | **3** – Access controls |
| [security-testing-plan.md](security-testing-plan.md) | Automated tests, monthly dependency scans and log reviews, fix deadlines, penetration test | **6** – Security assessments |
| [incident-response-plan.md](incident-response-plan.md) | Severity levels, roles, response steps, 24-hour bank notification, templates, checklist | **7** – Incident response |

Data retention (requirement 2) and the overall overview are in [../procredit-compliance.md](../procredit-compliance.md).
